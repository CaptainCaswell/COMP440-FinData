# COMP 440 - FinData

## Project Overview

This project will explore the feasibility of developing an algorithm capable of building a stock portfolio that can outperform that of stock indexes, such as the S&P 500. Machine learning techniques, such as unsupervised learning, will be applied to predominantly US-based stock market data to identify patterns and evaluate potential strategies to build and improve algorithms. The focus is on experimentation and analysis rather than achieving guaranteed performance improvements.

## Objectives

* Apply basic machine learning and statistical techniques
* Prepare financial datasets for data mining and knowledge discovery tasks
* Address and remediate data quality issues
* Analyze patterns and trends through evaluation and presentation
* Formulate recommendations for stock selection based on identified patterns and trends

## Approach

The project will follow an iterative and exploratory approach:

* Collect and prepare stock market data
* Develop and evaluate unsupervised machine learning models
* Experiment with simple strategies based on model outputs
* Compare results against benchmarks, such as the S&P 500  * 

The exact models and strategies may evolve as the project progresses.

## Deliverables

* Working code demonstrating experiments and results
* Output (e.g., graphs, metrics, or logs) illustrating model performance
* Research poster summarizing finding

## Proposed Evaluation

1. Engagement and Progress Reporting (20%)
    * Regular communication with instructor
    * Evidence of ongoing work and iterative development
    * Willingness to explore and adjust the approach
    * Bi-weekly meetings
2. Implementation and Results Analysis (50%)
    * Functional code and use of machine learning techniques
    * Effective data preparation and handling
    * Exploration of machine learning approaches
    * Application of relevant statistical methods to ensure data quality
    * Evaluation and presentation of pattern and trend analysis
3. Documentation (30%)
    * Minimal but clear summary of what was done
    * Enough detail to understand the work and results
    * Research Report
